## Architecture for Replit + Windows desktop screenshots

### 1) Keep Replit as the AI agent backend
- Use Replit for:
  - LLM orchestration (agent logic, planning, “ask the user” flows)
  - Web screenshots (Playwright/Selenium or screenshot API like Browserless/Urlbox) [docs.browserless](https://docs.browserless.io/rest-apis/screenshot-api)
  - PDF → images (PyMuPDF/pdf2image) [python.plainenglish](https://python.plainenglish.io/python-libraries-for-extracting-images-from-pdfs-6394d85b5135)
  - Storing results in Replit’s database or object storage

### 2) Run a small Windows client for desktop screenshots
On your Windows machine:
- Create a tiny HTTP server (Python Flask/FastAPI) that wraps your PowerShell script
- The Replit agent calls this server when it needs a desktop screenshot

**Windows client code (Python + Flask):**
```python
# screenshot_server.py (run on Windows)
from flask import Flask, request, jsonify
import subprocess
import os
import tempfile

app = Flask(__name__)

SKILL_PATH = r"<path-to-skill>"  # Update this
PS_SCRIPT = os.path.join(SKILL_PATH, "scripts", "take_screenshot.ps1")

@app.route("/screenshot", methods=["POST"])
def screenshot():
    data = request.json or {}
    mode = data.get("mode", "default")
    path = data.get("path")
    region = data.get("region")
    window_handle = data.get("windowHandle")
    
    cmd = ["powershell", "-ExecutionPolicy", "Bypass", "-File", PS_SCRIPT]
    
    if mode == "temp":
        cmd.extend(["-Mode", "temp"])
    elif mode == "activeWindow":
        cmd.append("-ActiveWindow")
    elif region:
        cmd.extend(["-Mode", "temp", "-Region", region])
    if path:
        cmd.extend(["-Path", path])
    if window_handle:
        cmd.extend(["-WindowHandle", window_handle])
    
    try:
        result = subprocess.run(cmd, capture_output=True, text=True, check=True)
        output_path = result.stdout.strip() or path or os.path.join(tempfile.gettempdir(), "screen.png")
        
        # Return image as base64
        with open(output_path, "rb") as f:
            import base64
            img_b64 = base64.b64encode(f.read()).decode()
        
        return jsonify({"success": True, "image": img_b64, "path": output_path})
    except Exception as e:
        return jsonify({"success": False, "error": str(e)}), 500

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

Run it on Windows: `pip install flask` then `python screenshot_server.py`

### 3) Expose your Windows client via ngrok (so Replit can reach it)
On Windows:
```powershell
ngrok http 5000
```
Copy the HTTPS URL ngrok gives you (e.g., `https://abc123.ngrok.io`).

### 4) Add the screenshot tool to your Replit agent
In your Replit code (Python example):

```python
# replit_agent.py
import requests
import base64

WINDOWS_SCREENSHOT_URL = "https://YOUR-NGROK-ID.ngrok.io/screenshot"

def take_desktop_screenshot(mode="default", region=None, path=None, window_handle=None):
    payload = {"mode": mode}
    if region:
        payload["region"] = region
    if path:
        payload["path"] = path
    if window_handle:
        payload["windowHandle"] = window_handle
    
    resp = requests.post(WINDOWS_SCREENSHOT_URL, json=payload, timeout=30)
    data = resp.json()
    
    if data.get("success"):
        return data["image"]  # base64 PNG
    else:
        raise Exception(f"Screenshoot failed: {data.get('error')}")
```

Call this from your agent when the user wants a desktop/window screenshot.

## “Ask the user” UX in Replit

Replit has built-in chat UI—use it for interactive prompts:

### Pattern 1: Simple radio buttons (if using Replit Agent/Chat)
```python
def ask_user(question, options):
    """Returns the user's selected option"""
    # In Replit Chat, format as a question with choices
    choices = "\n".join([f"- {opt}" for opt in options])
    prompt = f"{question}\n\nChoices:\n{choices}\n\nReply with your choice:"
    return prompt  # Your LLM will wait for user response in chat
```

Example flow:
```python
# Agent detects need to choose window
windows = ["Chrome — Dashboard", "VS Code — main.py", "Excel — Budget"]
question = "Which window should I screenshot?"
prompt = ask_user(question, windows)

# Send to user in chat, wait for reply
user_response = await send_to_chat(prompt)  # Replit's chat interface
selected = user_response.strip()

# Now capture that window
if "VS Code" in selected:
    img_b64 = take_desktop_screenshot(mode="activeWindow")
```

### Pattern 2: Use Replit’s database to store pending choices
```python
# Store pending choice
db["pending_choice"] = {"question": question, "options": options, "agent_state": "waiting"}

# When user responds in chat, update and resume agent
if user_message in options:
    db["user_choice"] = user_message
```
