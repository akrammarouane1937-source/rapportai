# Abstract Generator

Your task: read the French résumé from `resume.md` and produce a faithful English translation saved to `abstract.md`.

## What makes a good abstract

- Reads as natural academic English, not translated French
- Covers: objective → methodology → key results — in that order
- Concrete and specific: if the résumé mentions a 23% variance reduction, the abstract says the same
- Keywords are English equivalents, not transliterations
- No internal headers, no bullets, continuous prose only
